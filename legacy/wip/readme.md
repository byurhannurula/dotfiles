## 🚀 Quick Start

1. **Clone this repository:**
   ```bash
   git clone https://github.com/yourusername/dotfiles.git ~/dotfiles
   cd ~/dotfiles
   ```

2. **Capture your current configuration (recommended):**
   ```bash
   ./setup.sh --capture
   ```

3. **Run the complete setup:**
   ```bash
   ./setup.sh --full
   ```

4. **Or run individual components:**
   ```bash
   ./setup.sh terminal apps          # Terminal + Apps only
   ./setup.sh development macos      # Development + macOS preferences
   ```

5. **List currently installed apps:**
   ```bash
   ./list-installed-apps.sh
   ```

6. **Export app lists for configuration:**
   ```bash
   ./scripts/export-app-lists.sh     # Creates files to update apps-config.txt
   ```

## 🛠️ Usage

### Initial Setup
Run the main setup script on a fresh macOS installation:
```bash
./setup-macos.sh
```

The script will:
1. Install Xcode Command Line Tools
2. Install and configure Homebrew
3. Install essential CLI tools and development software
4. Set up Oh My Zsh with plugins and themes
5. Configure Git and shell environment
6. Install GUI applications
7. Set up development directory structure
8. Configure VS Code extensions

### List Current Installations
Before running setup, you can inventory your current system:
```bash
./list-installed-apps.sh
```

This will show:
- Homebrew packages (formulae and casks)
- Node.js versions
- Python/Ruby/Rust versions
- Database tools
- VS Code extensions
- macOS applications

### Apply Individual Configurations
You can also apply specific configurations manually:

```bash
# Apply zsh configuration
cp config/.zshrc ~/.zshrc
source ~/.zshrc

# Apply git configuration
cp config/.gitconfig ~/.gitconfig
cp config/.gitignore-global ~/.gitignore-global
git config --global core.excludesfile ~/.gitignore-global

# Apply VS Code settings
cp vs-code/settings.json ~/Library/Application\ Support/Code/User/settings.json
```

## 📋 Manual Steps

Some steps require manual configuration after running the script:

1. **Configure Powerlevel10k theme:**
   ```bash
   p10k configure
   ```

2. **Set up SSH keys for Git:**
   ```bash
   ssh-keygen -t ed25519 -C "your_email@example.com"
   ```

3. **Sign in to applications:**
   - GitHub CLI: `gh auth login`
   - GitLab CLI: `glab auth login`
   - VS Code: Sign in to sync settings

4. **Configure iTerm2:**
   - Import the provided plist file
   - Set up color schemes and fonts

## 🔧 Troubleshooting

### Common Issues

**Homebrew installation fails:**
```bash
# Check if Xcode Command Line Tools are installed
xcode-select -p
# If not installed:
xcode-select --install
```

**NVM not working:**
```bash
# Reload shell configuration
source ~/.zshrc
# Or restart terminal
```

**Permission issues:**
```bash
# Fix Homebrew permissions
sudo chown -R $(whoami) /opt/homebrew/*
```

**VS Code extensions not installing:**
```bash
# Install VS Code CLI manually
# Then run:
code --install-extension ms-python.python
```

### Getting Help

1. Check the script output for specific error messages
2. Ensure you have a stable internet connection
3. Make sure you have sufficient disk space
4. Try running individual sections of the script manually

## 🔄 Updating

To update your environment:

```bash
# Update Homebrew packages
brew update && brew upgrade && brew cleanup

# Update npm packages
npm update -g

# Update Oh My Zsh
omz update

# Update VS Code extensions
code --list-extensions | xargs -L 1 echo code --install-extension
```

Or use the built-in function:
```bash
update_all
```

## 🔒 Security & Privacy

### **What's Safe to Commit:**
- ✅ Setup scripts and configurations
- ✅ App lists and preferences
- ✅ Clean template configurations

### **What's NEVER Committed (Protected by .gitignore):**
- ❌ **SSH keys** (private and public)
- ❌ **Personal configurations** with paths/tokens
- ❌ **Application preferences** with personal data
- ❌ **Database configurations** with credentials
- ❌ **Backup directories** (`current-*/`)
- ❌ **Environment files** (`.env`, etc.)

### **Backup Security:**
- Backups are created locally only
- **NO SSH KEYS** are ever copied (neither public nor private)
- Only SSH config file is backed up (no keys)
- Personal data stays on your machine
- `.gitignore` prevents accidental commits
- Multiple layers of protection against key exposure

### **Sharing Your Dotfiles:**
1. Fork this repository
2. Customize `apps-config.txt` for your needs
3. Modify configurations in `config/` folder
4. **Never commit personal backups**

## 📝 Notes

- The script is designed to be idempotent (safe to run multiple times)
- Your existing configurations are backed up to the `current/` directory
- The script prefers Homebrew installations for easier maintenance
- All configurations are version-controlled for easy rollback
